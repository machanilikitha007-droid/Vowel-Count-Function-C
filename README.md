# Vowel Count Using Function in C

This program uses a user-defined function to count the vowels present
in a string.

## File

vowel_count.c

## Concepts Used

- Function definition
- Function call
- Character array
- String processing
- Return value

## How to Run

gcc vowel_count.c -o vowel_count
./vowel_count

## Sample Output

Enter a string: Hello World
Number of vowels = 3
